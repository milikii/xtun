## 5. 开工约束

- 新一轮先记录 HEAD、已有修改和运行内容摘要；保留当前未提交实现，按 `-R` 子项补修并留下旧问题反例与新结果。
- 核心默认仍为最新官方已发布版本，包含预发布；一次动作锁定，下一次重新选择。`v26.9.9` 是可复现依据，不等于本机已安装。
- 新装默认与旧安装选择分开；不隐式轮换 UUID/密钥/path，不改变架构、节点编号或已确认客户端。
- 本机迁移矩阵增加实际的 `0.11.14 bundle / state v2 / Xray 26.3.27`，保留历史 state v1 用例；不猜测 state v2 来源。
- `show-links --node N` / `--qr --node N`、安装 H3 开关及 `change-h3` 已实现；`upgrade --reinstall` 与 `export-client` 仍属计划，不预发可执行教程。
- `recover [--yes]` 已实现：有 pending 时先检查原因并显式恢复，再继续新写动作；原动作恢复成功仍不等于原动作成功。
- 后续故障注入继续使用隔离环境；本机生产保持现场，测试 VPS 不改 SSH 密码/配置。日志内容、包、系统用户、实时网络参数和内核不纳入自动文件回退。
