## 3. W02 交付

**代码：**

- `lib/base/env.sh`：操作 ID 用 `mktemp -d` 唯一化（不再依赖秒级时间戳）；每次操作写 `manifest.tsv`（op_id/路径/原本是否存在/归属/意图/快照/摘要）；单操作同一路径只记第一次快照且不可被后续内容覆盖；不存在的路径记 `existed=0/create`；失败返回非零而不是静默。
- 首次接管原件单独存放于 `/var/lib/xtun/originals`（`ORIGINALS_ROOT`），与会轮转的事务备份分离；登记表只认第一次。
- `prune_backup_sessions` 只轮转带 `completed` 的会话；失败/中断现场保留。
- `lib/generators.sh`：接管主配置前先 `record_takeover_original`。
- `lib/base/runtime.sh`：`restore_nginx_main_config` 重写为「首次原件 → 旧备份里最早的一份 → 保留当前文件并报告」，不再写发行版默认模板；旧版遗留清理不再停 `warp-svc`，Cloudflare WARP 客户端文件归入「已保留」；`remove_managed_paths` 记录删除项。
- `lib/install.sh`：装包前逐包记录归属（原本是否已安装）；`--purge` 只卸载自己装的；旧安装没有记录时全部保留并列为未能确认。
- `lib/cli/core.sh`：卸载输出分为「已删除 / 已保留 / 未能确认」；haproxy/nginx 若安装前已存在则不停不 disables，只摘配置并 reload；ACME 只删本域名的 `_ecc` 目录，保留 acme.sh 本体和其它域名证书；原件登记目录只在原件真的还原后才清理。

**本机验证：** `smoke ok`、ShellCheck 全绿；新增 `tests/cases_ownership.sh` 五个用例（首次快照不可变、同秒两会话轮转且失败现场保留、清单字段、有无原件与旧布局迁移的恢复、卸载归属与报告）。

## 4. 遗留与后续输入

- **保守卸载留下的端口占用：** 旧安装卸载时不认识自己装过的 haproxy，按共享资源保留，进程继续占 `:443`（配置已删）。此时重装会在 443 预检失败，需要用户先停它。W02 的取舍是「不许停别人的服务」，这是预期后果；重装/重建向导（W05）需要识别「占用者是我们刚保留的服务」并给出可执行动作或明确提示。
- 旧布局（0.11 及更早）nginx 原件迁移只有本机用旧布局备份复核，未在实机重放；如需再证，可在测试 VPS 造 `BACKUP_ROOT/YYYYmmdd-HHMMSS/etc/nginx/nginx.conf` 后走卸载。
- 实机验证结束后测试 VPS 处于「xtun 已卸载、nginx 保持运行、haproxy 已停、夹具已清理、hysteria 未动」的状态；后续工单可随时从源码重装。
