## 2. W03 交付

### 2.1 公开解析原语（H04）

- `lib/change/workflow.sh` 新增并作为公开路径唯一入口：`option_take_value`（`--opt value` 与 `--opt=value` 等价，内联空值 `--opt=` 直接拒绝）、`validate_option_value`（缺值/空值在解析阶段失败）、`reject_flag_assignment`（无值开关收到 `--flag=value` 报「是无值开关，不接受 = 值」，不再落进「未知参数」）、`record_arg_group`/`reset_arg_groups`（互斥组判定与出现顺序无关，报「互相冲突」）。
- 参数规格分隔符由 `:` 改为 `|`：ECH 配置值里就含 `https://`，用冒号分隔会被 `read` 截断——这本身就是 H04 的一个实例。
- `lib/change/requests.sh`、`lib/change/commands.sh`、`lib/cli/sni.sh`、`lib/cli/core.sh`、`lib/cli/install.sh` 全部改走 `option_take_value` + `OPTION_ARGS_CONSUMED`，不再各自 `shift 2`。

### 2.2 存在性与显式优先（H04）

- `install_flag_specs` 补互斥组；`--no-ipv6` 从带值选项改为无值开关（组 `ipv6`），`--server-ip6` 同组：`--no-ipv6 --server-ip6 …` 与反序都报冲突。
- `xtun.sh`：新增 `SERVER_IP_PRESENCE` / `SERVER_IP6_PRESENCE`（absent / provided / disabled），由 `mark_install_option_presence` 在解析时记录。
- `lib/install/input.sh` 的 `prepare_install_inputs` 按存在性分支：provided 不探测也不再询问；disabled 强制清空，探测结果与旧 state 都不能把它重新打开。

### 2.3 地址校验（H07）

- `lib/base/env.sh`：修掉 `is_ipv4` 里 awk `END { exit 0 }` 恒真的缺陷（`not-an-ip`、`999.999.999.999`、`1.2.3` 以前全部通过）。
- 新增 `is_ipv6_address` 真实解析：`::` 压缩、组数上限、单冒号位置、IPv4-mapped；`is_global_ipv6` 基于它做 2000::/3 判定。
- 新增 `ensure_server_ip_format`（IPv6 填进 `--server-ip` 时明确指向 `--server-ip6`）、`ensure_server_ip6_format`、`require_valid_ipv4_like_host`（纯点分数字但不是合法 IPv4 时按 IPv4 报错，而不是当域名放过）；`validate_install_inputs` 先校验地址再校验其它字段。
- WARP IPv6 内网地址校验改用 `is_ipv6_address`。

### 2.4 证书模式（H09）

- 内部统一规范字符串，UI 快捷编号由 `cert_mode_choice_value` 负责；acme-dns-cf 的编号从 3 改为 4——历史上 3 被 `normalize_cert_mode` 规范化成 existing，菜单显示 3 时直接回车会偷偷换模式。
- `--cert-mode 3` 仍按历史语义映射 existing，旧命令行脚本不改变行为。

### 2.5 推荐命令真的可执行（H10）

- `apply-config --manage-nginx-main` / `--no-manage-nginx-main` 进入真实工作流：接管、还原、状态翻转都有实际动作；没有原件时不翻转状态，报「找不到」并非零退出。
- `apply-net-opt --bbr-kernel joey|none` 进入真实工作流。
- `lib/base/runtime.sh` 新增 `NGINX_MAIN_RESTORE_RESULT`（not-managed / missing / restored / deleted / legacy-restored / unconfirmed）；`find_legacy_nginx_original` 跳过带 `# Generated by xtun.sh` 的备份，不再拿自己生成的副本冒充原件「还原成功」。
- 删除已死的 `nginx_main_config_debian_default_text`；帮助、README、ARCHITECTURE 与程序一起变更。
