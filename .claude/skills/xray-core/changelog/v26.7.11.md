# v26.7.11（预发布版）

本文件是人工审阅摘要；字段结论必须回到对应 tag 的源码或补丁核对。

- 传输 method 兼容旧 network；root 增加 env；Finalmask 增加 XMC。
- 限制面向公网的无加密 VLESS/Trojan 出站，移除 VMess/Shadowsocks 的 none/zero/plain 选项。
- REALITY 服务端此时加入默认 minClientVer=26.3.27；该默认值在 v26.9.8 再次调整。
